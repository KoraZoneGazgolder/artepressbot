# artepressbot

Дневник давления и таблеток (Telegram-бот).

Семейный бот: у каждого свой дневник. Работает в Docker, позже без смены кода переносится на VPS.

## Что умеет

- Давление своими цифрами одним сообщением. `120/80 72` — только пример формата, не запись по умолчанию
- Выгрузка дневника в CSV: кнопка «Таблица» или `/export`
- Напоминания измерить давление (по умолчанию **09:00** и **20:00**, Europe/Moscow). Их можно выключить или сменить время в «Настройки» / `/settings`
- Несколько препаратов с дозировкой и своим временем; бот спрашивает «Выпил?» — кнопки Выпил / Пропустил / Позже (повтор через 20 мин). В дневник пишется фактическое время нажатия «Выпил»
- Семья: `/start` → пара вопросов (кто вы, откуда узнали о боте) → заявка админу → одобрение кнопкой
- Первый, кто напишет `/start`, становится админом (либо ID из `.env`)
- Обратная связь: `/feedback` — сообщение админу, он может ответить прямо в боте
- Админу: `/stats` — сводка по семье (замеры, средние значения, дисциплина по таблеткам)
- Добрые пасхалки: поздравления в праздничные дни, тёплые заметки за регулярность замеров, ответ на «спасибо»

## Запуск

1. В [@BotFather](https://t.me/BotFather) создайте бота и скопируйте токен.
2. В этой папке:

```powershell
copy .env.example .env
```

3. В `.env` вставьте `BOT_TOKEN=...`. По желанию укажите `ADMIN_TELEGRAM_ID` (свой числовой id, его покажет бот командой `/id`).
4. Запуск:

```powershell
docker compose up --build -d
docker compose logs -f
```

5. Напишите боту `/start`.

Остановка: `docker compose down`. База SQLite лежит в Docker-томе `bp_diary_data` и не пропадает при пересборке.

## Команды

| Команда | Кто | Зачем |
|---|---|---|
| `/start` | все | регистрация / заявка |
| свои цифры, пример `120/80 72` | семья | записать давление |
| `/list` | семья | список измерений давления |
| `/export` / «Таблица» | семья | CSV дневника |
| `/today` | семья | сегодня: давление и таблетки |
| `/meds` | семья | список, «выпил», смена дозы, удаление |
| `/addmed` | семья | добавить препарат: название, дозировка, время |
| `/settings` / «Настройки» | семья | вкл/выкл и время напоминаний о давлении |
| `/help` / «Справка» | все | справка (кнопка сверху на клавиатуре) |
| `/feedback` | семья | написать админу: вопрос, идея, пожелание |
| `/users` `/pending` | админ | семья и заявки |
| `/stats` | админ | статистика по семье: замеры, средние, дисциплина по таблеткам |

## Потом на VPS

Тот же `docker compose up -d`. Когда появится домен, можно сменить polling на webhook — код к этому готов по структуре, менять заранее не нужно.
