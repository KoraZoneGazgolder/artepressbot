# artepressbot

Дневник давления и таблеток (Telegram-бот).

Семейный бот: у каждого свой дневник. Работает в Docker, позже без смены кода переносится на VPS.

## Что умеет

- Давление одним сообщением: `120/80 72`
- Выгрузка дневника в CSV: кнопка «Таблица» или `/export`
- Напоминания измерить в **09:00** и **20:00** (Europe/Moscow)
- Несколько препаратов с своим временем; бот спрашивает «Выпил?» — кнопки Выпил / Пропустил / Позже (повтор через 20 мин)
- Семья: `/start` → заявка админу → одобрение кнопкой
- Первый, кто напишет `/start`, становится админом (либо ID из `.env`)

## Запуск

1. В [@BotFather](https://t.me/BotFather) создайте бота и скопируйте токен.
2. В этой папке:

```powershell
copy .env.example .env
```

3. В `.env` вставьте `BOT_TOKEN=...`. По желанию укажите `ADMIN_TELEGRAM_ID` (свой числовой id, его покажет бот командой `/id`).
4. Запуск:

```powershell
docker compose up --build -d
docker compose logs -f
```

5. Напишите боту `/start`.

Остановка: `docker compose down`. База SQLite лежит в Docker-томе `bp_diary_data` и не пропадает при пересборке.

## Команды

| Команда | Кто | Зачем |
|---|---|---|
| `/start` | все | регистрация / заявка |
| `120/80 72` | семья | записать давление |
| `/list` `/history` | семья | список измерений |
| `/export` / «Таблица» | семья | CSV дневника |
| `/today` | семья | сегодня: давление и таблетки |
| `/meds` | семья | список, «выпил», удаление |
| `/addmed` | семья | добавить препарат и время |
| `/users` `/pending` | админ | семья и заявки |

## Потом на VPS

Тот же `docker compose up -d`. Когда появится домен, можно сменить polling на webhook — код к этому готов по структуре, менять заранее не нужно.
